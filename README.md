# Sales Performance Dashboard

## Overview
Interactive Power BI dashboard analyzing Superstore 
sales data (2015-2018).

## Key Metrics
- Total Sales: $2.26M
- Total Orders: 4,922
- Top Category: Technology (36.59%)

## Visuals
- KPI Cards
- Sales by Category (Pie Chart)
- Sales Trend by Date & Category (Line Chart)
- Regional Sales Performance (Bar Chart)
- Interactive Date Slicer

## Tools Used
Power BI | Excel | Superstore Dataset (Kaggle)

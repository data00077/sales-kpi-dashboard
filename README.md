# 📊 Sales Performance Dashboard — Superstore 2015-2018

![PowerBI](https://img.shields.io/badge/Power%20BI-Dashboard-yellow) ![Excel](https://img.shields.io/badge/Excel-Data%20Cleaning-green) ![Status](https://img.shields.io/badge/Status-Complete-green)

## 📌 Overview
Interactive **Power BI dashboard** analyzing Superstore sales data (2015–2018) with KPI cards, regional performance, category trends, and an interactive date slicer.

## 🎯 Objective
- Track total sales, orders, and top category KPIs
- Analyze sales performance by region and category
- Visualize monthly sales trends over 4 years
- Enable interactive filtering via date slicer

## 📊 Dataset
- **Source:** Kaggle — Superstore Sales Dataset
- **Size:** 9,800 rows
- **Period:** 2015–2018

## 🛠️ Tech Stack
| Tool | Purpose |
|---|---|
| Power BI | Dashboard & visualizations |
| Excel | Data cleaning & preparation |
| Kaggle | Dataset source |

## 📈 Key Metrics
| Metric | Value |
|---|---|
| Total Sales | $2.26M |
| Total Orders | 4,922 |
| Top Category | Technology (36.59%) |
| Best Region | West |

## 📊 Dashboard Visuals
1. **KPI Cards** — Total Sales, Order Count, Top Category
2. **Pie Chart** — Sales by Category (Technology / Furniture / Office Supplies)
3. **Line Chart** — Monthly Sales Trend by Category
4. **Bar Chart** — Regional Sales (West / East / Central / South)
5. **Date Slicer** — Interactive filter by Ship Date
